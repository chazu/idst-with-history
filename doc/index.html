About IDST

IDST is an experimental programming language system that explores prototype-based programming, dynamic compilation, and seamless interoperability with C and other languages. The system consists of:

  • Pepsi - A prototype-based language with Smalltalk-like syntax
  • Coke - A functional abstract syntax processor and assembler
  • Runtime System - Introspective and intercessory runtime support
